## ✨ Features

- Modern dark gradient background  
- Very large temperature display (°C ⇄ °F side by side)  
- Huge weather emoji representation  
- Clean & friendly error messages  
- Press **Enter** in city field or click button  
- Centered layout, emoji font support  
- Basic but polished QSS styling  

## Quick Start

```bash
# 1. Clone (or just download the file)
git clone https://github.com/your-username/weatheria.git
cd weatheria

# 2. Install dependencies
pip install PyQt5 requests

# 3. Run
python weather.py
